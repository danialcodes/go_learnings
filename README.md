# Basic Server and hello world response

## This branch contains basic learning and hello world server for the go programming languages.

 - `go mod init <module_name>` - Initializes a new module, creating a go.mod file.
 - for accessing dotenv file we can use `github.com/joho/godotenv` package.
 - for creating a server we can use `github.com/gin-gonic/gin`.
 - `go get <package_name>` - Downloads and installs the specified package and its dependencies.
